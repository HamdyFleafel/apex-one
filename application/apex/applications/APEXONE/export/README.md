\# APEXONE Application Export



\## Purpose



This folder contains Oracle APEX application export files.



\## Naming Convention



Format:



f<Application\_ID>.sql



Example:



f1000.sql



\## Export Source



Oracle APEX 26.1



\## Deployment



Exports are installed using:



install/install.sql



\## Rules



\- Never edit exported APEX files manually.

\- Always export from APEX Builder.

\- Commit every application version.
