\# APEXONE Enterprise Platform

\# Database Naming Standards



\*\*Version:\*\* 1.0.0-alpha.3



\*\*Author:\*\* APEXONE Development Team



\---



\# Purpose



This document defines the official naming conventions used throughout the APEXONE Enterprise Platform.



Every database object must follow these standards.



\---



\# General Rules



\- Use UPPERCASE for all database objects.

\- Use singular business names where appropriate.

\- Use underscores (\_) between words.

\- Avoid spaces.

\- Avoid Oracle reserved words.

\- Keep names descriptive and consistent.



Example



GOOD



APP\_USERS



BAD



Users



userTable



tblUsers

\# Version Control



Every SQL script must contain:



\- Header

\- Version

\- Author

\- Description

\- Change History



Example



\------------------------------------------------------------

APEXONE Enterprise Platform



Script : app\_users.sql



Version : 1.0.0



Author : APEXONE Team



Description : Create APP\_USERS table

\------------------------------------------------------------
