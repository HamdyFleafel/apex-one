# APEXONE Architecture Documentation

This directory is the single authoritative location for architecture documentation.

## Ownership

- `ARCHITECTURE_BASELINE_v1.0.md` — binding architecture baseline.
- `OWNERSHIP_MATRIX.md` — canonical responsibility ownership and anti-duplication rules.
- `REPOSITORY_STRUCTURE.md` — canonical repository structure.
- `DATABASE_*.md`, `*_ARCHITECTURE.md`, `*_MODEL.md` — database architecture details.
- `DEPENDENCY_MATRIX.md` and `MODULE_DEPENDENCIES.md` — dependency rules.
- `DATA_FLOW.md` — system/data flow.
- `SECURITY_ARCHITECTURE.md` and `SECURITY_MODEL.md` — security architecture.

Architecture documentation does not contain implementation source code.
