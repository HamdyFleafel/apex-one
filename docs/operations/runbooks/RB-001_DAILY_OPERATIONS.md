\# Daily Operations Runbook



\## Purpose



This runbook defines the daily operational activities required to maintain the

APEXONE Enterprise Platform.



\---



\## Daily Checklist



\### Database



□ Database Instance Running



□ Listener Running



□ PDB Open (FREEPDB1)



□ Tablespace Usage Checked



□ Autoextend Status Verified



□ Invalid Objects Checked



□ Alert Log Reviewed



\---



\### Oracle APEX



□ Workspace Accessible



□ Application Accessible



□ Authentication Working



□ Session Creation Successful



\---



\### ORDS



□ ORDS Running



□ REST Enabled



□ Static Resources Accessible



\---



\### Backup



□ Backup Completed



□ Export Verified



□ Backup Directory Available



\---



\### Monitoring



□ Space Report Reviewed



□ Top Segments Reviewed



□ Blocking Sessions Checked



□ Failed Jobs Checked



\---



\### Git



□ Working Tree Clean



□ No Pending Commits



□ Latest Changes Pushed
